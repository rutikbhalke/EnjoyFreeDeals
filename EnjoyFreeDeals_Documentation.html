1. System Architecture & Ecosystem

EnjoyFreeDeals is an end-to-end deal aggregation and price comparison ecosystem consisting of four primary components:

1.1 Core Components

Component Technology Role & Responsibilities
Android App Kotlin, Jetpack Compose / XML, Retrofit, Coroutines Native mobile app delivering personalized feed, price alerts, notifications, and deal discovery. Consumes backend API.
Web Portal React 18, Vite, TypeScript, Tailwind CSS, Lucide Icons Fast web interface for browsing deals, search, store comparisons, blog posts, and administrative management.
Backend API Node.js 20+, Express.js, Supabase Client SDK Secure API layer for affiliate link resolution, telegram loot scrapers, deal scoring, price tracking, and admin health checkers.
Database & Auth Supabase (PostgreSQL 15), RLS, Realtime Replication Centralized transactional store, user authentication, role-based access control, and automated deal expiration workflows.

1.2 Architectural Security Boundary

Critical Security Separation: Public vs. Service Role
  • SUPABASE_ANON_KEY: Allowed in Android app and web client for read-only / public operations guarded by PostgreSQL Row Level Security (RLS).
  • SUPABASE_SERVICE_ROLE_KEY: STRICTLY restricted to the Node.js backend. Never bundled in Android APKs, web code, or client repositories.
  • Clients communicate through the backend API (http://localhost:5000 or production Vercel base URL) for administrative and privileged updates.

3.1 Key Tables Created in the Consolidated Migration

  • products & product_offers: Canonical catalog and multi-store offers with foreign key cascading.
  • fetch_runs: Tracks run duration, items discovered, items updated, and errors.
  • saved_deals & recently_viewed_deals: Per-user engagement features with composite unique keys.
  • price_alerts, price_tracking_requests & tracked_products: Dynamic price drops and scheduler queue.
  • telegram_channels, telegram_sources & scrape_logs: Real-time Telegram loot monitoring.

4. Complete REST API Reference

The backend serves JSON REST endpoints under the /api prefix.

4.1 System & Health Endpoints

Method Path Description
GET /api/health Returns server uptime, timestamp, memory, and status (ok).
GET /api/health/supabase Performs live query against Supabase to verify connectivity.
GET /api/admin/database/tables Inspects all 37 database tables, row counts, and latency.

4.2 Deals & Catalog Endpoints

Method Path Description
GET /api/deals Fetches active deals with optional category, search, and pagination.
GET /api/deals/featured Returns top-scored trending and hot loot deals.
GET /api/deals/:id Returns complete deal details, store comparisons, and price history.
POST /api/deals/:id/upvote Records community upvote and increments upvote_count.

4.3 Price Tracking & Comparison Endpoints

Method Path Description
POST /api/track-price Extracts platform product ID (Amazon ASIN / Flipkart PID) and starts tracking.
GET /api/price-history?url=... Retrieves 30/90/180-day price trends for chart rendering.

4.4 Telegram Ingestion Endpoints

Method Path Description
POST /api/telegram-scraper/fetch Triggers manual scrape run across configured Telegram public loot channels.
POST /api/telegram-scraper/webhook Receives real-time Telegram channel message payload from bot webhooks.

5. Automation, Scrapers & Telegram Sync Engine

5.1 Scraper Architecture

The deal ingestion engine automatically scrapes, parses, normalizes, and ranks deals from Telegram channels and merchant feeds.

Script / Task Schedule Functionality
scripts/sync-genie-loot.js Every 15-30 mins Scrapes public preview pages of top Telegram channels, parses titles, discount percentages, and original prices.
scripts/sync-price-tracking.js Hourly Refreshes prices for all items in tracked_products and logs changes to price_history.
.github/workflows/telegram-sync.yml Cron Schedule Automated GitHub Actions workflow triggering serverless scrape runs.
cleanup_expired_deals() Every 1 min (pg_cron) Hides expired deals, mark zero-stock items as inactive.

5.2 URL Normalization & Platform Detection

Links are cleaned to strip tracking pixels and extract standard affiliate parameters:

  • Amazon: Standardizes amzn.to shortlinks to canonical amazon.in/dp/{ASIN} and appends associate tag.
  • Flipkart: Extracts pid query parameters and generates standardized affiliate links.
  • Other Platforms: Detects Myntra, Ajio, Meesho, Croma, Nykaa, and Tata Cliq automatically.

SUPABASE_ANON_KEY=<YOUR_PUBLIC_ANON_KEY>

Android Networking Note
When testing in Android Studio Emulator, use http://10.0.2.2:5000 to reach the host machine backend.

6.2 Web Frontend Configuration

The web client runs on Vite with React 18 and Shadcn UI. The development server proxies /api requests directly to the Node backend:

// web/vite.config.ts
server: {
  port: 8080,
  proxy: {
    '/api': {
      target: 'http://localhost:5000',
      changeOrigin: true
    }
  }
}

6.3 Admin Panel Access

  • URL: http://localhost:8080/admin (or /admin/database)
  • Admin Secret Key: enjoyfreedeals_admin_secret
